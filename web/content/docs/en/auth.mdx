## Console users

Register and sign in via `/api/v1/auth/*`. Sessions use cookies; the SPA stores a Bearer token for API calls when needed.

## Access tokens

Create tokens in the console for scripts and agents. Workspace tokens scope MCP and workspace OpenAPI paths to a single workspace (`workspace_id` in the API).

## Roles

Platform admins manage users and settings. Workspace members have roles (viewer, editor, …) enforced on each `/api/v1/workspaces/{workspace_id}/*` route.
