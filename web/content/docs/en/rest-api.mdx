## Base URL and versioning

All normative routes live under `/api/v1`. Legacy unversioned routes are gated off by default (HTTP 410).

## OpenAPI documents

Three published specs share one implementation (see also the [interactive reference](/swagger)):

- [`/openapi/v1.json`](/openapi/v1.json) — full surface
- [`/openapi/v1/platform.json`](/openapi/v1/platform.json) — platform administration
- [`/openapi/v1/workspaces.json`](/openapi/v1/workspaces.json) — per-workspace operations (`/api/v1/workspaces/{workspace_id}/*`)

## Session vs token

Browser console uses session cookies and Bearer tokens after login. Automation uses platform or per-workspace access tokens — see Authentication.
