## Alignment with OpenAPI

MCP tools map to the same operations as OpenAPI v1. Prefer MCP when the client already speaks the protocol; use REST for generic HTTP integrations.

## Setup outline

Open Integration under System in the workspace sidebar: create an access token on the Access tokens tab and copy the MCP URL on the MCP tab. Configure your agent host with the token as Bearer credentials.
