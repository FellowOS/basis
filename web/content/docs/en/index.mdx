## What you can build on

Basis exposes versioned REST under `/api/v1/*`, per-workspace routes under `/api/v1/workspaces/{workspace_id}/*`, and OpenAPI documents at `/openapi/v1.json`. Agents can use HTTP MCP on each workspace.

- Platform API — users, workspaces, models, audit, settings
- Workspace API — ingest, ledger, search, graph, ontology, MCP
- MCP — tool surface aligned with the same operations as OpenAPI
