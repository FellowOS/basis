## 环境

Python 3.10+（uv）、Node.js 22+（Web）。

## 本地运行

仓库根目录：复制 `.env.example`，执行 `uv sync --extra dev && uv run basis`（API 8090）。在 `web/`：复制 `.env.example`，`npm install && npm run dev`（控制台 5173）。

注册第一个用户即成为平台管理员。

## 验证

打开控制台创建知识库并上传资料；需要精确请求结构时使用 [交互式 API 参考](/swagger)。
